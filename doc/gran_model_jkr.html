gran model jkr and jkr/analytical models

Syntax

model jkr [other model_type/model_name pairs]
model jkr/analytical [other model_type/model_name pairs]

The model name applies to particle-particle and particle-wall contacts:

pair_style gran model jkr tangential history
fix walls all wall/gran model jkr tangential history mesh ...

pair_style gran model jkr/analytical tangential history
fix walls all wall/gran model jkr/analytical tangential history mesh ...

Description

Both styles implement the Johnson-Kendall-Roberts adhesive normal-contact law and share contact history, damping, stiffness, tangential coupling, wall handling, and detachment behavior. They differ only in how contact radius and normalized force are evaluated.

jkr is the compatibility implementation. It uses the original lookup table and requires both properties:

fix id all property/global workOfAdhesion peratomtypepair ntypes values ...
fix id all property/global resolutionJKR scalar value

workOfAdhesion is in J/m² in SI units. resolutionJKR controls table spacing; 1e-4 is a common value. Existing interpolation and startup reporting are preserved.

jkr/analytical requires workOfAdhesion but not resolutionJKR. For normalized overlap d = delta/deltac and g = sqrt(a/a0), it evaluates the larger positive stable root:

2 cbrt(6) g^4 - (4/3) cbrt(6) g - d = 0
a/a0 = g^2
Fn/Fc = 4 ((a/a0)^3 - g^3)

Cardano/Ferrari is used for -1 ≤ d ≤ 0 and an equivalent hyperbolic cubic form for d > 0, avoiding large-compression cancellation. An established adhesive contact detaches below d = -1.

Both models support tangential history and tangential no_history, with cohesion and rolling models off and the default surface model.

Required material properties

Define youngsModulus, poissonsRatio, coefficientRestitution, coefficientFriction, and workOfAdhesion. The legacy model additionally requires resolutionJKR.

References

Johnson, Kendall and Roberts (1971), Surface energy and the contact of elastic solids, Proceedings of the Royal Society A 324, 301–313.

Marshall (2009), Discrete-element modeling of particulate aerosol flows, Journal of Computational Physics 228, 1541–1561.
