fix balance command

Syntax

fix ID group-ID balance Nfreq thresh shift dimstr Niter stopthresh

Examples

fix lb all balance 1000 1.10 shift xyz 10 1.05
fix lb all balance 0 1.05 shift xy 20 1.01

Description

This fix dynamically shifts Cartesian processor subdomain boundaries so each MPI rank owns approximately the same number of particles. The processor grid topology is unchanged and the fix group is accepted but ignored.

The trigger is max(nlocal)/average(nlocal). Positive Nfreq values force checks on exact multiples; zero checks on normal neighbor rebuilds. An initial Verlet setup check is also made.

The unique characters in dimstr select axes for density-dependent multisection. Niter is the per-axis iteration limit and stopthresh is the convergence target. Triclinic boxes use reduced coordinates and all cuts remain finite, ordered, and nonzero in width.

Redistribution migrates registered per-particle state, then rebuilds normal communication, contact, neighbor, multisphere, and mesh ownership data.

Restart and output

Split arrays are not stored in restart files. Output commands do not trigger balancing. The scalar is post-balance imbalance; vector entries are maximum particles on one rank, iteration count, and pre-balance imbalance.

Restrictions

Only particle-count shift balancing is supported. Wedge domains, non-Verlet or CUDA runs, minimization, multiple balance fixes, PASCAL exchange-event coupling, and z balancing in 2d are rejected.

Related commands: processors, dump custom/vtk.
